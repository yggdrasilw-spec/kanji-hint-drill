# 全小学校配当漢字への字形評価拡張：実装報告

2026-10-10。対象：`C:/Users/user/kanji-hint-drill`。既存HEAD `0a536ec`。
今回のユーザー指示に従い、旧引き継ぎ文書の代表字段階を越えて全1,026字へ展開した。
元の設計・引き継ぎ・資源調査は変更していない。

## 実装した範囲

配当80／160／200／202／193／191字すべてに、字別の評価データを用意した。
5,567部品出現、6,100候補規則割り当て、1,071共通／個別テンプレート。
鉄は生成候補10件を実行せず `legacy-iron-v2` の既存12件を使用する。
したがって通常のAPIが参照する規則の割り当ては6,102件である。
件数は全細部の教育上の承認や校正率を表さない。

| レイヤー | 今回の実装 | 学習記録への扱い |
|---|---|---|
| identity | 部分対応による必要な線の過不足、字別の接続候補、囲みの中の横線数、明示した長短・突出条件 | 新規規則の候補失敗は通常モードでは自己確認。鉄の既存判定は維持 |
| writing | 画数・順番・方向、短い終画、偏の払い上げ・接続・上下端、はね・はらいの形 | 追加項目は初期オフ。課題は確認付き正解・書き方の復習 |
| beauty | 指定した線の長短、月形の本体幅、目の指定した間隔、横線の平行・右上がり | 初期オフ。助言だけで自力正解・stage・streak・due・再出題を変えない |

SVGのXML階層、original・variant・position・part・number・partial、画の型を保持。
同名部品の複数出現・重複所属を別の出現として記録し、元のグループ番号を規則の永続IDには使わない。
部首ハンターの非連続rangesを保持し、部首クイズで一つに絞る処理は流用しない。
全1,026字で既存pathsとの完全一致を再確認した。元の部首アプリは変更していない。

画の対応には未対応のダミーを用意し、遠い線を無理に不足画へ割り当てない。
なぞり直しは一つの見た目の線、適合する短い断片の接続は分割された一画の候補として扱う。
原入力の画数・方向・順番は別に保持する。位置・一様倍率・限定した回転の補正を使い、部品だけを横に伸ばす正規化は行わない。
入力品質や対応が不確かな場合はuncertain／unavailableとし、未評価を合格にしない。

## 字・部品形ごとの判断

| 対象 | 適用する条件・個別の扱い |
|---|---|
| 日・目・見、同じ囲み部品を持つ字 | 外枠の安定した線から内部領域を得て横線を数える。上辺・下辺・側線は内側に数えない |
| 見 | 横線が足りない／余分でも総画数だけで中断しない。別の画の欠落で全体画数が相殺されても内部を確認 |
| 目 | 上辺・内部2本・下辺で生じる3つの空間だけを間隔評価。横線不足のときは間隔助言を重ねない |
| 土／士・未／末 | 単独字の必要な長短を明示した規則で比較。nestedやleftを単独字の規則へ無条件に含めない |
| 週の内部の土形 | 単独の土の下横画長短を誤適用しない。部品情報を保持し、字全体の接続候補を評価 |
| 千 | 最上部の斜めの線を縦線が突き抜ける条件にはしない。干と同じ横画2本の形としても扱わない |
| 夫／天・牛／午 | 対象の縦線・横線と必要な突出／上下端を字別指定。候補規則としてレビュー待ち |
| 知 | 矢の単独形から分離した `arrow.left-compact`。末端区間の長さ、横画に対する終点位置、方向を組み合わせる。口の移動だけでは長い払いと断定しない |
| 三・青 | 下の横画を長く、中を短くする指定した比較対。青の上部と下の月の内部を混ぜない |
| 金 | 単独形は下横画＞中横画＞上横画の比較対。金偏の第8画は払い上げとして別扱い |
| 金偏・土偏・玉偏 | 偏の形として払い上げなどを明示。金偏の新規条件はwritingであり、鉄の互換条件とは別プロファイル |
| 利などの刂 | 左短縦・右主縦の投影長を比較。はね・震えによる弧長増加で順位を変えない |
| 月・明・服・青 | 単独、右側、左側、下部、original=肉を別プロファイルにする。側線を複数の高さで測り、本体幅／高さを評価。下端の払い・はねを外接幅に混ぜない |

許容字形の細部を印刷形への一致だけで誤字と断定しない方針は、[文化庁の説明](https://www.bunka.go.jp/prmagazine/rensai/kotoba/kotoba_009.html)も確認した。
この総論から個々の接触・突出の正誤を承認した扱いにはしていない。
部品情報の扱いは[KanjiVGのSVG仕様](https://kanjivg.tagaini.net/svg-format.html)を確認した。

## 画面と保存

- 開始画面の先生向け設定に骨組み・書き方・美文字の追加項目を置いた。
- 「この字だけの調整」は実際に適用するカテゴリと規則だけを表示。実効値と継承を表示する。
- 全体カテゴリoffは最優先。有効なカテゴリ内では規則別→字別カテゴリ→共通設定の順。
- 判定開始前に設定と字別調整を固定。古い画面・古い判定の丸を残さない。
- 児童には答案上の線・点・部品領域を丸で示す。欠落した線の先端は捏造しない。
- 局所の横線数の指摘を包括的な過不足・曖昧な接続候補より優先する。
- 複数指摘の選択で丸と説明を切り替え、説明はaria-liveで通知する。
- 旧保存キー／version=1／shapePolicy／beautyNotesを保持し、engineVersion、ruleSetVersion、構造化policySnapshot、規則ID・版・レイヤー・状態・理由を追加保存する。
- 読込は文字列・配列数・数値を制限。未知の規則IDは記録としてだけ保持し、実行しない。過去の記録を再採点しない。

## 試し方

ローカルサーバーを起動し、`shape-review.html` を開く。
今回の稼働URLは `http://127.0.0.1:8898/shape-review.html`。

1. 「見」を選び、内側の横線を1本減らす／増やす／なぞり直すを比べる。
2. 通常モードでは自己確認、検証用モードでは候補の測定結果が出ることを比べる。
3. 「消して試し書き」で自分の筆跡を確認する。検証画面は学習記録を変更しない。
4. 練習画面では見のカードだけを選ぶ。先生設定で画数と横線数を独立に操作できる。
5. 知の長い右払いは「短い終画」を有効にする。三・金・利の長短、月の細さ、目の間隔は美文字の各項目を有効にする。

## 残っている確認

全1,026字の共通評価・部品候補の取り込みと実行は実装した。
一方、次は未完了として全字の対応一覧に残す。

- 新規identity規則ごとの規範資料・許容書体・部品形の人による承認。
- 代表字以外の各細部について、独立した誤り・許容例・境界を網羅するフィクスチャ。
- すべての複雑な部品・終筆・字固有の条件の専用規則。全細部の完成扱いにはしない。
- 児童・複数の書き手・端末からの目視ラベル付き筆跡収集と、書き手を分離した閾値校正。
- 実際の筆の停止・筆圧の検出。現在は座標から終筆の形だけを確認する。

新しいidentity候補は、上記確認を経るまで自動誤答に昇格させない。
通常の練習は候補失敗を自己確認へ回し、OCRを利用できない場合も従来の自己確認を維持する。
コミット・プッシュ・公開は今回実行していない。

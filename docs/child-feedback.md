# 1年生向けの指摘文

`shape/child-feedback.mjs` が、測定結果から子ども向けの `childText`・`childLabel` を作る。先生向けの測定値・規則文と、正誤・復習の集計はそのまま保つ。

## 言葉と内容
- 「1かくめと 2かくめ」のように対象を明示。専門語の交差・突出・接触・経路・終端・対応・箇所などを使わない。
- 動作は「くっつけて とめよう」「はなそう。くっつけないでね」「つきぬけるように かこう」。交差済みなら「つきぬけているよ」と伝える。
- 短い線は長く、長い線は短く。離れすぎた線は「くっつけずに ちかづける」。逆向きの助言をしない。
- はね・はらい・すきま・上下左右・大きさは短いひらがなで示す。不確かな線の対応は、直し方を断定しない。
- 正解した字の見本との差・美文字は「きれいに かく ヒント」。正誤や自力で書けた記録を変えない。

## 例
「3かくめの おわりは、きちんと はねよう。」
「1かくめは、もうすこし ながく かくと、きれいだよ。」
「いろの ついた ところの よこの せんは、すきまを おなじ くらいに あけよう。」
「じの ぜんたいを、もうすこし ほそながく かくと、きれいだよ。」

## 字全体の助言
既存の「部品の配置・大きさ（beautyLayout）」が有効なときだけ、元の109×109の座標で大きさ・縦横比・位置を見て、最大2件の表示専用の助言を加える。初期設定は見ない。全体と字別の見ない設定を尊重する。文字の輪郭が極端に薄い「一」などには縦横比の助言を出さない。暫定の差の目安はゆるめ40%・標準30%・厳しめ20%。これを字の正しさの基準にしない。実際に判定する項目がないときに、無根拠に「大きく」「細く」と言わない。

## 縦の中心線・左右の長さ（美文字のみ）
設定に「たての中心線にそろえる」「縦画から左右の長さをそろえる」を追加。初期設定は両方とも見ない。全体と字別の設定を尊重し、正誤判定・自力正解・復習時期から分離する。

「十」「土」など指定した候補のうち、手本の中心にまっすぐな縦画があり、それにつながる横画がほぼ左右均等のものだけを対象とする。「右」「左」等に一律に左右対称を要求しない。線の対応が不明な場合も指摘しない。

中心線は実際のマスの中心（109座標でx=54.5）とのずれ。左右の長さは実際の縦画との交点から横画の左端・右端までを測り、どちらを延ばすかを明示する。対象の線だけを色で示す。閾値は暫定値であり、児童の実筆跡で校正した数値ではない。

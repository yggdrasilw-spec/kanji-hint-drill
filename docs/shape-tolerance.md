# 全漢字の細部チェックと許容幅

## 網羅の定義

全1,026字の9,662画に、始点・終点・経路・終端方向・長さを割り当てる。二画の全47,138組をお手本上の交差1,543組・接触4,920組・離れ40,675組に分類する。5,567箇所の部品のうち、根の1,026箇所は全体の線で、親を持つ4,541箇所は相対配置で確認する。追加の幾何項目は99,989件、既存の意味・部品別規則と合わせて107,879件。

これは幾何的に比較できる箇所の棚卸しである。お手本で触れる線を、教育上必ず触れるべき線と同一視しない。許容字体、教育上の必須性、実筆跡での精度は別のレビュー対象であり、完了したとは表示しない。筆圧・穂先・止める力は記録されていないため測定しない。

## 距離と角度

字全体を一つの移動・拡大縮小・12度以内の傾きで重ね合わせる。部品だけを伸縮させて合わせない。比率はこの共通座標系を使い、画面の固定ピクセル数に依存しない。設定では基準が100pxの場合を図と数値で例示する。

|比較項目|比率の基準|ゆるめ|標準|厳しめ|
|---|---|---:|---:|---:|
|全画の始点・終点のずれ|字全体|14%|10%|6.5%|
|全画の経路・折れ曲がりのずれ|字全体|18%|13%|9%|
|終端の向きと手本の差|角度|50度|35度|22度|
|接触の隙間・接触点での余分な突出|字全体|10%|7%|4.5%|
|交差の隙間・不足する突出|字全体|13%|9%|6%|
|離れた二画の隙間が増える量|字全体|18%|13%|8%|
|部品の中心・大きさのずれ|親部品|18%|13%|8.5%|
|一画の長さの差|実際と手本の長い方|50%|35%|22%|
|部品別の縦線の収まり|基準の横線|22%|16%|6.5%|

離れの下限は手本の隙間の35%から字全体の1.5%を引いた値（0未満は0）。小さい筆離れや接触差を必須扱いしない。位置・経路は境界±1.5%、交差・接触は±1.2%、長さは±3%、終端方向は±4度などの境界域を自己確認に回す。部品別の規則は、その部分の基準線や意味上の条件で別途測る。

はねは終端近くの複数の長さの方向変化を見る。最小の曲がり角はゆるめ20度・標準30度・厳しめ42度を基本に、手本の曲がりが小さければ軽減する。終わりが手本の方向から110度を超えて反転した場合も見直し候補。はねのない手本に強制しない。右払いの終端方向差は40度・30度・20度（境界±3度）。

## 判定と画面

鉄専用の設定・分岐は廃止。字にかかわらず同じ部品・幾何処理を通す。旧専用キーと、近い線だけを拾った旧接触設定は現行設定から除く。保存済み共通設定と過去の学習履歴は維持する。

文字認識 → 骨組み → 書き方 → 美文字の順で扱う。未レビューの骨組みの候補は自己確認へ回す。お手本由来の接触・離れや細部だけで、認識できた字を不正解にしない。新しく棚卸しした手本由来の差（reference-candidate）と任意の接触は、赤い参考指摘にしても自力正解や復習時期を変えない。画数・順序・方向や明示的に選んだはねの練習などの課題は別に扱う。美文字の助言も自力正解や復習時期を変えない。

初期値は位置・経路・交差・接触・離れをゆるめ。全体の「見ない」は字別調整に優先する。画の対応が不確かなら、特定できた実際の線群を示す。場所を特定できない場合はその旨を明記し、手本の位置に偽の赤丸を置かない。

指摘は4件ずつ切り替える。赤い線・丸と説明は同じ選択に対応する。字別設定は種類別に8件ずつ、先生向けの確認項目は6件ずつ。先生向けは手本と答案の同じ対象線、測定値と許容値を表示する。狭い画面では書く画面・項目と図と数値・全字一覧を分ける。筆跡が同じ字として認識されたかを確認する画面と、全体の正誤に影響しない試し書きを分ける。

履歴には全項目の状態別件数、設定・字別上書き、問題のある指摘を記録する。正常項目の明細は省略。指摘は重大度順に128件まで保存し、切り詰めた場合は明示する。最大324項目の字でも、個別上書きは512件まで扱える。旧履歴を読み直して得点を付け直さない。

## 再生成・検証

`node scripts/build-shape-details.mjs` で棚卸しと分類表を再生成する。`--check` で生成物の一致を確認できる。`node scripts/audit-shape-details.mjs` は全1,026字の追加99,989項目を標準で有効にして測定し、`data/shape-detail-validation.json` に字別の結果を残す。原データと生成器・幾何処理のハッシュを記録する。

`node --test tests/*.test.mjs` は全字のお手本・変形、端点・曲がり・終端・長さ・交差・接触・離れ・部品配置の変形例、指摘の座標、無効化、履歴互換を確認する。8898番のHTTPサーバーで `node tests/shape-usability.cjs` 、`node tests/shape-advice-browser.cjs` と `node tests/shape-details-browser.cjs` を実行すると、固定した認識応答で実際の入力・赤表示・設定操作と320〜1280pxの表示を確認する。認識モデルの精度や児童の実筆跡による校正を済ませたことにはしない。

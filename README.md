# ひとふでヒント

東京書籍「新編 新しい国語」に合わせた、漢字を書く・読むドリルです。**文を読んで漢字を決める例文形式**で、単独の文字や単語だけを問題として出しません。大きなボタン、やさしい色、ひらがな中心の案内で、低学年でも使えるようにしました。「あそびかた → 学年と単元 → はじめる」の順に選びます。スマートフォンでは開始ボタンを画面の下に表示します。

## 起動

```
node scripts/serve.mjs
```

http://127.0.0.1:8897/ を開きます。`file://`ではモデル・教材データを読み込めません。静的なHTTPサーバーでも動作します。音声入力にはHTTPSまたはlocalhost、対応ブラウザ、マイクの許可が必要です。Webサイトのホスティング設定は含みません。

## 読みの練習と縦書き

- **かんじを かく**：文全体を表示し、書き取る部分に□と読みがなを付けます。「かさを さして、□の なかを あるきます。」なら読みは「あめ」、答えは「雨」です。文脈から漢字を決め、１文字ずつ書きます。
- **よみを こたえる**：同じ例文を表示し、色と線で示した部分の読みを答えます。文のほかの部分は答えに含めません。書く問題と読む問題の学習記録・復習予定は分けて保存します。
- **例文**：独自に作成した986件で全1,026字・全単元をカバー。意味のある文脈、読み、対象文字を一緒に管理します。低学年では高学年の漢字を含む語彙を優先しません。周囲の未習漢字は、注記された読みでひらがなに置き換えます。文のある問題だけを出し、単独の読みを筆順で区別する出題や最初からの１画目表示をやめました。
- **うつ**：ひらがなで入力し、「できた！」で判定します。カタカナ・全角英数の正規化、空白・句読点の除去、IMEの変換中のEnter対策に対応。例文で指定した読みを正解とし、文脈に合わない別の辞書読みを一律には受け付けません。
- **はなす**：日本語のWeb Speech APIを使用。認識した読みは答え欄に入れ、児童が確認してから判定します。認識結果が漢字の場合は、そのことばに対応する教材の読み候補を表示し、選んでもらいます。未対応・マイク拒否・通信失敗時は入力や手書きに切り替えられます。画面移動・問題変更・判定後は認識を止め、古い認識結果を破棄します。
- **かく**：ひらがなを１文字ずつ手書きし、「この もじを よみとる」で候補を表示。候補を選ぶと答え欄に追加します。認識には既存のDaKanjiモデルのひらがなラベルを使い、問題の正解を候補の絞り込みには使用しません。候補の確認・訂正・末尾削除ができます。
- 読みのヒントは、KanjiVGのひらがな筆順から１画ずつ増やします。ヒントと手書き画像は別に描画します。
- 問題のことば・読みと入口の案内は**縦書きが初期設定**。「もんだいの むき」で横書きに切り替えられ、設定を保存します。操作ボタン・入力欄・記録は読みやすさと押しやすさを優先して横書きです。

手書きの認識はブラウザ内で処理します。**音声はブラウザ提供の認識サービスに送信される場合があります**。マイクは「はなす」ボタンを押したときだけ起動します。実マイク・児童の発話による認識精度は未測定です。

## 機能

### 漢字カードから選ぶ

「かんじを えらぶ」は1〜6年生の全1,026字を学年別のカードで表示します（80・160・200・202・193・191字）。カードをタップすると黄色く光り、チェックが付きます。もう一度タップすると外れます。光った字だけを、書く問題・読む問題・セッション内の復習の対象にします。学年をまたいだ選択、学年ごとの全選択・解除、全学年の全選択・解除に対応。学年フィルターと漢字検索は表示だけを絞り、選んだ字を解除しません。

選んだ字と選択方法はこの端末に保存されます。「単元から えらぶ」に切り替えると、従来の単元選択を使えます。二つの選択は独立しており、単元で選んだ字がカードの出題範囲に混ざることはありません。カードの選択が空なら練習開始を無効にします。初期画面は漢字カードです。既存の単元選択・学習記録・字形の確認設定は保持します。

出題は既存の例文形式です。複数学年を選んだ場合も、それぞれの字の配当学年に合わせて例文を選び、周囲の未習漢字をひらがなにします。配当は`data/curriculum.json`の各字の`grade`から取得し、学年ごとの字数は[文部科学省の学習指導要領解説](https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf)と照合しています。

「鉄」を試すには、検索欄に「鉄」と入力し、そのカードだけを光らせて開始します。鉄は既存の互換プロファイルを維持します。全1,026字の共通・部品評価と字別設定を追加しています。新規identity規則の問題検出は通常の練習では自己確認に回します。

検証：`node tests/characters.test.mjs`（全字・学年・出題範囲・未習字・復習）、`node tests/characters.cjs`（タップ・保存・絞り込み・範囲切替・鉄のみの練習・モバイル）。ブラウザ検証には起動済みのサーバーを使い、`APP_URL`でURLを変更できます。

### 練習と記録

- 1〜6年生の1,026字。単元を個別選択、全部選択、指定単元までの一括選択。
- 文中の□と読みがなを提示し、1字を手書き。周囲の漢字は選んだ範囲と前学年までに限定し、未習漢字はひらがなに変換。
- 複数の例文・読み方で出題。教科書でその読み方を習う単元は未転記のため、**字の出題範囲が教科書対応、例文は独自作成**。教科書の例文は複製していません。
- 1画目、次の画、答えの順にヒント。ヒント・答えは認識画像に入れません。
- DaKanji v2 ONNXによる文字認識。KanjiVGによる画数・方向・書き順・位置の補助分析。
- 自動判定が曖昧な場合やモデルが使えない場合は、お手本との比較を促し、自己確認として保存します。自己確認は自力での正解・習得に数えません。
- ヒント正解、誤答、答えを見た問題はセッション内で3問程度あけて再出題（追加は最大4問）。誤答は即復習対象、ヒント正解は10分後、自力の正解は1・3・7・14日後。書き順などに課題がある正解は補助ありとして復習対象に残します。
- localStorageで語彙・読みごとに保存。復習日時、誤認識候補、誤答分析、ヒント利用履歴を保持。JSON書き出し・読み込みに対応。読込は最新記録を優先して統合。

現時点の確認はKanjiVGの線を入力する自動検証が中心です。実際の児童の筆跡で認識率を測定したものではありません。読みの音声テストはブラウザAPIの結果・エラー・遅延イベントを模擬しています。追加エンジンでは必要な線や囲み内部の横線の過不足を候補として指摘します。意味の理解を診断する機能はありません。筆順の位置判定は字枠上の座標を比較するため、字の配置によって補助確認が出る場合があります。

## 全1,026字の細部チェック

鉄を含む全字を共通エンジン `component-engine-3` で確認します。鉄専用の設定・判定分岐はありません。

- 9,662画すべてに、始点・終点・経路と折れ曲がり・終端方向・長さの5項目を割り当て。
- 二画の全47,138組を、お手本上の交差・接触・離れに分類。交わる位置、交点から先の長さ、隙間や突き抜けを、小さな違いを許容して比較。
- 5,567箇所の部品を棚卸し。親を持つ4,541箇所は親部品に対する配置と大きさを評価し、根の部品は字全体の線の過不足で確認。
- 新規の幾何項目は合計99,989件。既存の意味・部品別の規則と合わせて107,879件。全字のお手本を新規99,989項目の標準設定で評価し、範囲外・要確認・測定不能は0件。
- 文字認識、骨組み、書き方、美文字を分離。お手本由来の関係を教育上の必須とは断定せず、細部だけで認識できた字を不正解にしません。お手本由来の参考指摘と美文字では、自力正解や復習時期を変えません。画数・書き順や選択したはねの練習などの課題とは分けます。
- 初期値は位置・経路・交差・接触・離れを「ゆるめ」。既存の保存済み共通設定は尊重し、全体が「見ない」の項目は字別調整でも再開しません。
- 赤表示と説明を一つずつ対応づけます。指摘は4項目ずつ、字別設定は種類別に8項目ずつ表示。先生向けの確認画面は種類・ページで選び、手本と答案の対象線、測定値、許容上限を並べて確認できます。
- はね・払いの形や終端の向きは見ますが、筆圧・穂先・止める力は測定しません。幾何項目の網羅、教育上の必須性のレビュー、児童・大人の実筆跡での校正は別です。

先生向け：[字形の確認](shape-review.html)。`shape-review.html?char=鉄` のように字を直接指定できます。手本の筆跡、内側の横線の増減、なぞり直し、任意の画の終点のずれ、試し書きを学習履歴へ影響させず比較できます。狭い画面は「書く・赤表示」「項目・図・数値」「全字一覧」で切り替えます。

判定値と処理範囲：[許容幅の説明](docs/shape-tolerance.md)。字別一覧：[細部の棚卸し](data/shape-detail-coverage.json)。全件検証結果：[標準設定のお手本監査](data/shape-detail-validation.json)。旧 [shape-coverage.json](data/shape-coverage.json) と実装報告は、部品規則を先に追加した時点の記録です。

履歴には判定時の共通設定と字別上書き、状態別の全件集計、重要な指摘を保存します。正常項目の明細は省略し、指摘明細は重大度順に最大128件。上限で省略した場合はフラグを残します。保存・再読込で過去の得点を付け直しません。

## データとライセンス

教材対応はユーザー提供の令和8年度の教科書画像から転記した単元・ページ・漢字。学習する月は記録していません。年度・版の表記はアプリ画面に出していません。教材対応表の公開利用条件は未確認です。

`data/curriculum.json`には単元対応、筆順パス、辞書から抽出した読み・語彙例を収録します。`data/provenance.json`に取得元と処理を記録しています。**実際の出題文は`data/sentences.mjs`**に記載し、`sentences.mjs`で対象文字・読み・文中位置を解釈します。これらの例文は独自作成です。`data/kana.json`にはKanjiVGから抽出したひらがな86文字の筆順パスを収録します。ひらがなもKanjiVGの帰属・CC BY-SA 3.0を適用します。

- 筆順パス：KanjiVG、Ulrich Apel、CC BY-SA 3.0。既存の`kakijun/svg`から抽出したデータ。派生した筆順データも同条件で扱います。[公式サイト](https://kanjivg.tagaini.net/) / [ライセンス](https://creativecommons.org/licenses/by-sa/3.0/)
- 語彙・読み：EDRDG JMdict / KANJIDIC2、CC BY-SA 4.0。抽出・適応した辞書データも同条件で扱います。[利用条件](https://www.edrdg.org/edrdg/licence.html)
- 認識モデル：Dariyooo (DaAppLab)、DaKanji Single Character Recognition v2.0、MIT。Character recognition powered by machine learning from Dariyooo (DaAppLab)。[モデルの配布元](https://github.com/dariyooo/DaKanji-Single-Kanji-Recognition/releases/tag/v2.0)。原文ライセンスは`assets/DAKANJI-LICENSE.txt`。
- ONNX Runtime Web 1.22.0、Microsoft、MIT。原文ライセンスは`assets/ONNXRUNTIME-LICENSE.txt`。

手書きの推論はブラウザ内です。筆跡をサーバーに送信しません。初回はアプリのサーバーからライブラリ・モデルを取得します。Google Fontsを参照し、利用できない場合は端末のフォントに切り替わります。音声入力の処理・送信先は利用ブラウザのWeb Speech APIに依存します。

## 再生成と検証

`scripts/download-assets.mjs`でモデル・辞書・実行ライブラリをダウンロードします。モデルとラベルのZIPを`source/model`、`source/labels`に展開し、`scripts/build-data.mjs`を実行するとデータを再生成します。2〜6年の転記元は現在`C:/Users/user/.cache/kanji-curriculum`、1年の対応はスクリプト内です。パスは別端末で変更が必要です。辞書原本・ZIP・QAスクリーンショットは`.gitignore`で除外しています。

```
node tests/core.test.mjs
node tests/reading.test.mjs
node tests/sentences.test.mjs
node tests/browser.cjs
node tests/reading.cjs
node tests/contexts.cjs
```

ブラウザ検証はこの端末のPlaywrightとEdgeを使用します。サーバーを起動してから実行してください。別のポートでは環境変数`APP_URL`を指定します。モデルの明暗条件の検証は`tests/model.cjs`です。読みの検証では、キーボードの正誤、モード別記録、実モデルでのひらがな候補、音声結果・マイク拒否・遅延結果、320/390/768pxの画面と横書き切替を確認します。

ひらがな筆順の再生成：`node scripts/build-kana.mjs /path/to/kanjivg/svg`。元SVGは同梱しません。生成データの出典・ライセンスは`data/kana.json`内にも記載しています。

```

node scripts/validate-shape-data.mjs
node tests/shape-expansion.test.mjs
```

生成器はPython標準ライブラリのXMLパーサーを使い、既存pathsとの完全一致を確認します。元リポジトリは読み取り専用です。検証専用の筆跡は配信データから分離して `qa/shape/reference-fixtures.json` に生成します。検証には先に生成器を実行してください。ブラウザ検証の標準ポートは8898です。例：PowerShellで `$env:PORT="8898"; node scripts/serve.mjs`。
